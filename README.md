# Sistema de Préstamo de Equipos

Aplicación de línea de comandos para gestionar el préstamo de equipos
tecnológicos de un laboratorio universitario.

> Tarea 1 - Verificación y Validación (INF331).

## Estado

En construcción. La estructura del proyecto y los modelos de datos base ya
están definidos. Las funcionalidades de autenticación, solicitudes,
aprobaciones, operaciones y telemetría se incorporarán en los siguientes
commits sobre la rama `develop`.

## Tecnologías

- Python 3.10 o superior
- JSON para persistencia local
- `logging` para registro de eventos
- `sentry-sdk` para monitoreo de errores

## Instalación

```bash
git clone <URL_DEL_REPOSITORIO>
cd sistema-prestamo-equipos/codes
pip install -r requirements.txt
```
