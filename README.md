# Tarea 1 - Sistema de Préstamo de Equipos


## Descripción

El proyecto consiste en el desarrollo y prueba de un sistema de préstamo de equipos.

El sistema permite gestionar usuarios, equipos y solicitudes de préstamo, considerando diferentes roles, estados y reglas de negocio asociadas al proceso.

Además del desarrollo de la aplicación, el proyecto contempla actividades de Verificación y Validación (V&V), diseño y ejecución de casos de prueba, registro de defectos, trazabilidad de requerimientos y trabajo colaborativo mediante GitHub.

## Ejecución

Para instalar las dependencias necesarias:

```bash
pip install -r requirements.txt
```

Para ejecutar la aplicación:

```bash
python app.py
```


## Control de versiones

El desarrollo del proyecto utiliza **Git y GitHub** para mantener el historial de cambios y facilitar el trabajo colaborativo.
